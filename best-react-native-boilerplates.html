Best React Native boilerplates in 2026, compared

We make NativeExpress, one of the kits below, so weigh this page accordingly. Every fact comes from the project's own site or GitHub repository on the date above. We read their public pages and did not buy or test the paid kits. "Not listed" means the page we read didn't mention it, not that the kit can't do it.

If something here is wrong or out of date, write to contact@native.express and we'll correct it.

Short answer

Which one fits

You want the lowest price for a paid kit
Shipnative or Ship React Native, both $99 at the time of writing, against $229 for NativeExpress and $399 for Launchtoday.
You want Convex as your backend
Ship React Native recommends it, and Shipnative supports it. NativeExpress is built on Supabase only.
You also want to run on the web
Shipnative lists iOS, Android and web. NativeExpress covers iOS, Android and iPad.
You want your own Postgres API with tRPC
Launchtoday is built on tRPC, Postgres and Prisma.
You don't want to pay, and you'll build the rest
Ignite has the largest following at about 19,900 GitHub stars. Obytes has about 4,400 and includes an auth flow. Our own Mobile App Code Template adds a Supabase database and email sign-in.
You're building with Claude Code, Cursor or Codex on Supabase
This is what we built NativeExpress for. Its skills configure each integration and check the result, generate your theme, and in Claude Code submit the app to both stores from the terminal. Chat, image generation and camera scan are already wired up.
